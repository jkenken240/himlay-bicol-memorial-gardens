# Himlay Bicol Memorial Gardens

An elegant, responsive concept website for a proposed memorial garden serving Bicolano families.

**Live website:** [himlay-bicol-memorial.khen-guinez.chatgpt.site](https://himlay-bicol-memorial.khen-guinez.chatgpt.site)

![Himlay Bicol Memorial Gardens](public/himlay-hero.webp)

## About the project

Himlay was designed as an initial business presentation for a peaceful, family-centered memorial garden in the Bicol Region. The experience explains the proposed services with sensitivity, introduces the planning process, answers common questions, and provides a guided quotation inquiry.

## Features

- Responsive editorial-style landing page
- Custom Himlay visual identity and brand mark
- Proposed lawn-lot, family-estate, interment, and pre-need services
- Compassionate three-step planning guide
- Planned-location presentation for the Bicol Region
- Expandable frequently asked questions
- Mobile navigation with accessible interaction states
- Quotation inquiry form with a clear concept-mode confirmation
- Custom imagery, layered depth effects, and subtle motion

## Important notice

This website is an initial business concept. The exact municipality, services, prices, payment plans, availability, and contact channels remain subject to owner approval. The inquiry form currently demonstrates the intended user experience and does not send information to a backend.

## Technology

- TypeScript
- React 19
- Next.js 16
- Vinext and Vite
- Tailwind CSS 4 and custom CSS
- Cloudflare-compatible server output

## Run locally

The included build helpers require Linux or WSL, Node.js `22.13.0` or newer, and npm.

```bash
npm ci
npm run dev
```

Useful commands:

```bash
npm run lint
npm test
npm run build
```

## Main project files

```text
app/page.tsx          Page content, interactions, FAQs, and inquiry flow
app/globals.css       Responsive styling, imagery, and visual effects

public/               Himlay concept imagery and icons
```
